**When will the NT for Apple Silicon project be done?**

This strongly depends on your definition of "done," as that has multiple different but correct definitions, depending on what your expectations are and what you are hoping to get out of the project.

In general, this project should be assumed to be a continuous WIP (work-in-progress), things will be worked on and completed as they come up. Many things are incomplete and will eventually be completed over time. As such an ETA for when the project will become usable is very often not possible to indicate, and things should always be assumed to be done when they are done and not done otherwise.

For production use: this project will likely remain work-in-progress for a very long time, as it's a hobby project maintained by a few people, so time is often limited to address bugs or concerns. Please do not ever use this project in a serious production or mission-critical setting. The NTASP authors and maintainers do not assume any responsibility or liability for usage of the project or issues that arise because of it.

For hobbyist/casual use: the project is not really usable, while the absolute fundamentals are (barely) working, there's still many things that casual users expect and often demand to be working that aren't yet. it's strongly advised to NOT run this project yet on any machine that you intend to do real tasks on yet, Windows isn't yet usable for such scenarios. (Additionally: a second machine is required at the moment to bring up the Windows instance.)

In the raw sense: we have Windows barely booting with some fundamentals working but nothing beyond that. we're working on some core system blocks (ANS and AIC as of 1/1/2026) but right now the system can at least stay alive for a portion of time (albeit very slowly as the only boots that were tested were Windows to Go boots)
